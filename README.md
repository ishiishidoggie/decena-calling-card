# Jose Decena — Digital Calling Card

A clean, professional digital calling card / portfolio site for **Jose Decena**, Managing Director of Ascendant Global.

Designed to match the calling-card layout sketch and populated with content from the company calling card.

## Live on GitHub Pages

1. Create a new GitHub repository (public).
2. Upload all files in this folder (or push via git).
3. Go to **Settings → Pages**.
4. Under **Source**, choose **Deploy from a branch**.
5. Select branch `main` (or `master`) and folder `/ (root)`.
6. Save. Your site will be available at `https://<username>.github.io/<repo-name>/`.

## Add your photo

Place a square professional headshot at:

```
assets/self.jpg
```

Recommended size: 400×400 px or larger. The site will show a placeholder until the image is present.

## Structure

```
website/
├── index.html          # Main page
├── styles.css          # Styling
├── script.js           # Tab switching
├── assets/
│   ├── partners-000.jpg  # Company partners graphic
│   └── self.jpg          # (you add this)
└── README.md
```

## Tabs

- **About** — Roles & bio
- **Ascendant Partners** — Partner schools, industry partners & clients image
- **Ascendant Milestones** — Key achievements

Footer contains Australia & Philippines office addresses (linked to Google Maps), LinkedIn, and WhatsApp/Viber.
